# 01 - Ideation Phase

## Project Name
Medical Diagnosis Center by Service Portal (ServiceNow)

## Problem Statement
Patients often face difficulties in booking diagnostic tests, checking appointment availability, tracking appointment status, and accessing diagnostic reports. Diagnostic centers also require an organized system to manage patients, appointments, reports, payments, and administrative activities.

## Proposed Idea
Develop a Medical Diagnosis Center application using the ServiceNow platform and Service Portal to provide a centralized system for diagnostic test booking, appointment management, report handling, payment tracking, workflow automation, and administrative control.

## Target Users
- Patients
- Lab Staff
- Lab Managers
- System Administrators

## Key Features
- Patient registration
- Diagnostic test booking
- Appointment and time-slot management
- Prescription upload
- Appointment status tracking
- Diagnostic report management
- Payment status management
- Automated notifications
- Administrative dashboard
- Role-based access control
- Workflow automation

## Technology
- ServiceNow Platform
- ServiceNow Service Portal
- Flow Designer
- Business Rules
- Client Scripts
- ACLs
- Notifications
- ServiceNow Tables
